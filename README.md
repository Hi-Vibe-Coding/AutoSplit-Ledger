# AutoSplit Ledger - 店铺采购对账与自动平摊助手

用于**双人合伙开店**中，单方垫付采购款、多币种折算（美元/人民币）与账目平摊的网页工具。打开网页即可在线核对验算，并支持一键生成透明公式推演报告。

## 🌟 核心特性

- **纯前端零依赖**：基于单文件 HTML 现代轻量化架构，所有运算均在用户本地浏览器完成，绝不上传任何账单数据，保护隐私安全。
- **白盒透明验算**：点击“开始验算”后，详细打印每一步推演步骤与数学算式，杜绝黑盒结算争执。
- **智能 Markdown 表格粘贴导入**：直接复制 Markdown 表格（包含日期、服务名、金额币种及勾选符号 `✔️` / `√` 等），一键识别导入。
- **多币种实时折算**：支持美元（USD `$`）与人民币（RMB `￥`）多币种输入，汇率支持实时自由调整（默认 6.67）。
- **生成分享链接**：一键将当前编辑的账单通过 URL Hash 生成分享链接，发送给合伙人，对方在任意浏览器打开即自动恢复全部数据。
- **灵活扩展**：支持自定义双方称呼、支持调整分摊比例（默认 50%:50%）。

## 📐 平摊推演逻辑

以典型采购账单为例：
| 时间 | 产品服务 | 花费金额 | 支付方A | 支付方B |
|:---|:---|:---|:---:|:---:|
| 2026.10.22 | WebShare Static Residential IP | 3.5$ | ✔️ | |
| 2026.10.30 | 机场(蓝胖云)- 单月 | 12￥ | | ✔️ |
| 2026.11.03 | XMRTH机场(单月) | 16￥ | ✔️ | | 
| 2026.11.11 | ChatGPT Plus | 20$ | | ✔️ |

**推演步骤：**
1. **A 垫付总额** = 3.5美元 + 16人民币 = 3.5 * 6.67 + 16 = 39.345(人民币)
2. **B 垫付总额** = 12人民币 + 20美元 = 12 + 20 * 6.67 = 145.4(人民币)
3. **店铺总开销** = A支付总额 + B支付总额 = 39.345 + 145.4 = 184.745(人民币)
4. **每人应承担原始金额** = 184.745 / 2 = 92.3725(人民币)
5. **差额结算**：因 B 支付总额 (145.4) > A 支付总额 (39.345)，故最终由 **A 向 B 转账 145.4 - 92.3725 = 53.0275(人民币)**。
6. 转账完成后双方实际承担的支出均为 92.3725(人民币)，账目刚好清零持平。

## 🚀 开启 GitHub Pages 在线访问

本项目已配置自动化部署工作流：
1. 代码提交推送到 GitHub `main` 分支。
2. 进入 GitHub 仓库页面 -> **Settings** -> **Pages**。
3. 在 **Build and deployment** -> **Source** 下选择 **GitHub Actions**（或选择 **Deploy from a branch** 并选择 `main` 分支的 `/ (root)`）。
4. 部署完成后即可通过官方链接（例如 `https://<用户名>.github.io/<仓库名>/`）公开访问并分享给合伙人。
